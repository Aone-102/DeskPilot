# 🚀 DeskPilot (데스크파일럿) v2.0
> **컴퓨터 부팅 시 자동 실행되는 나만의 스마트 데스크탑 비서 & 스마트폰 무선 연동 생산성 시스템**

DeskPilot은 컴퓨터를 켰을 때 **바탕화면과 다운로드 폴더를 안전하게 자동 정리**하고, **오늘의 할 일과 메모를 관리**하며, **스마트폰(Android / iOS)과 QR 코드 1회 스캔으로 영구 무선 연동**되는 윈도우 데스크탑 비서 프로그램입니다.

외부 클라우드 서비스 가입이나 유료 구독 없이, **내 PC 자체가 초경량 프라이빗 로컬 서버로 동작**하여 가장 빠르고 안전하게 스마트폰과 데이터를 주고받을 수 있습니다.

---

## 💡 1. DeskPilot은 어떤 프로그램인가요?

매일 컴퓨터를 사용할 때 겪는 대표적인 불편함들을 해결하기 위해 제작되었습니다:
1. **어지러운 바탕화면과 다운로드 폴더:** 온갖 파일이 뒤섞여 있어 찾기 힘들고 컴퓨터가 지저분해지는 문제  
   👉 **안전 수칙에 기반하여 문서, 이미지, 압축파일, 미디어 등으로 스마트 자동 분류 및 100% 원클릭 되돌리기(Undo) 지원**
2. **어제 끝내지 못해 잊혀지는 할 일들:** 투두리스트에 적어두고 날짜가 지나면 잊어버리는 문제  
   👉 **자정 이후 컴퓨터를 켜면 어제 미완료 작업이 오늘 날짜로 자동 이월(`↻ 이월 N`)되며, 우선순위·마감일·소요시간 가중치 알고리즘으로 최적의 작업 순서 자동 정렬**
3. **컴퓨터 ↔ 스마트폰 간 파일 주고받기의 번거로움:** 사진이나 문서를 나에게 카톡으로 보내거나 이메일로 부치던 불편함  
   👉 **QR 코드 1회 스캔으로 영구 페어링되어, 폰에서도 PC에서도 드래그 앤 드롭으로 즉시 파일을 주고받는 QuickDrop 제공**
4. **외부 외출 중(LTE/5G) PC 원격 접근:** Wi-Fi가 달라도 내 컴퓨터의 할 일, 메모, 파일에 접근하고 싶을 때  
   👉 **내장된 Cloudflare Quick Tunnel을 켜면 암호화된 안전한 HTTPS 보안 주소로 어디서든 원격 접속 가능**
5. **실시간 자동 동기화:** 폰에서 할 일을 체크하거나 사진을 전송하면 **PC 화면을 새로고침(F5)하지 않아도 2.5초 내 즉시 화면에 자동 반영**
6. **스마트폰에서 내 컴퓨터 화면 및 작업 확인 (실시간 라이브 & 외부망 지원):** 다른 방이나 외출 중일 때 컴퓨터에서 무슨 작업이 진행 중인지 보고 싶을 때  
   👉 **스마트폰에서 현재 PC 모니터 화면을 무지연 실시간 라이브 스트리밍으로 띄워주고(화질 선택, RTT 레이턴시 표시, 전체화면 지원), 현재 실행 중인 프로그램 창 목록까지 한눈에 확인 가능 (외부 네트워크 Cloudflare 터널 접속 중에도 100% 정상 작동)**

## 🏗️ 2. 시스템 아키텍처 및 기술 구성

DeskPilot은 불필요한 무거운 프레임워크를 일절 배제하고, **순수 Python 표준 라이브러리와 모던 웹 기술**로 가볍고 신속하게 작동하도록 설계되었습니다.

### 🛠️ 기술 스택
- **백엔드 (Core Backend):** Python 3.12 (내장 `http.server`, `urllib`, `json`, `uuid`, `hashlib`, `subprocess` 등 표준 라이브러리 기반의 Zero-Dependency 아키텍처)
- **프론트엔드 (Frontend):** Modern HTML5 SPA, Tailwind CSS (반응형 PC 대시보드 & 모바일 웹앱 듀얼 UI), Lucide Icons, Vanilla JavaScript
- **보안 및 인증 (Security):** 6자리 일회용 OTP 페어링 코드, SHA-256 해시 기반 기기 인증 토큰(`X-DeskPilot-Device-Token`)
- **터널링 (Remote Access):** Cloudflare Quick Tunnel 데몬 내장 (LTE/5G 외부망 통신)
- **데이터 저장:** Windows `%APPDATA%\DeskPilot\` 디렉터리 내 영구 JSON 분리 보관 (전 구간 UTF-8 보장)

## 🌟 4. 핵심 기능 상세 안내

### 1) 🛡️ 안전 최우선 스마트 파일 정리 (PRD 5.2)
- **사용자 승인 후 동작:** 첫 실행 마법사를 거치기 전에는 어떤 파일도 임의로 이동하지 않습니다. (자동 정리 기본값: OFF)
- **사용 중인 파일 완벽 보호:** 수정된 지 60초 이내의 파일 및 웹 브라우저 다운로드 중 파일(`.crdownload`, `.part`, `.tmp` 등)은 자동으로 건너뜁니다.
- **개발자 코드 보호:** 코드 파일(`.py`, `.js`, `.json`, `.sql` 등) 분류는 기본 비활성화되어 소스 코드가 옮겨지지 않습니다.
- **바로가기 및 시스템 파일 보존:** `.lnk`, `.url`, `desktop.ini` 등은 절대 이동하지 않습니다.
- **안전한 기본 보관 위치:** 재귀 루프를 방지하기 위해 `문서\DeskPilot\정리된_파일`의 카테고리별 하위 폴더(`문서`, `이미지`, `압축파일`, `설치파일`, `미디어`)에 안전하게 분류됩니다.
- **100% 원클릭 되돌리기 (Undo):** 정리된 내역은 배치 단위로 기록되며, 언제든 [되돌리기] 버튼 하나로 원래 있던 바탕화면이나 다운로드 폴더 위치로 완벽 복구됩니다.

### 2) 📋 똑똑한 할 일 관리 & 자정 자동 이월 (PRD 5.3 & 7장)
- **자정 이후 자동 이월 (A2):** 어제 끝내지 못한 할 일은 앱을 켜면 오늘 날짜로 자동 이월되며 `↻ 이월 N` 배지가 붙습니다.
- **가중치 기반 자동 정렬:**
  - 우선순위 점수: 긴급(+40점), 높음(+30점), 보통(+20점), 낮음(+10점)
  - 마감일 점수: 마감일 지남(+30점), 오늘 마감(+20점), 3일 이내(+10점)
  - 소요 시간 점수: 30분 이내 작업(+2점)
  - 이월 보정 점수: 여러 번 이월된 중요 작업에 가산점 부여
- **실시간 스크래치패드 메모:** 빠르게 메모할 수 있는 연습장이 제공되며, 타이핑 중 0.6초 후 자동 저장되고 클립보드 복사를 지원합니다.
- **메모 ➡️ 할 일 즉시 변환 (Scratchpad to Tasks):** 메모장에 적어둔 여러 줄의 아이디어나 할 일 목록을 **[📋 할 일로 변환]** 버튼 하나로 모달 창에서 감지하여 원하는 항목만 체크박스로 선택, 기본 우선순위를 지정한 뒤 오늘 할 일로 즉시 일괄 등록할 수 있습니다. 변환 완료 시 해당 항목을 메모장에서 깔끔하게 자동 삭제하는 옵션도 제공됩니다.

### 3) 📱 스마트폰 QR 1회 연동 & 영구 재연동 (PC별 고유 QR 링크 지원)
- **각 PC마다 고유한 QR 링크 발급:** 각 컴퓨터마다 하드웨어 고유 노드 기반의 Server ID(`dp_xxxxxxxx`)가 발급되며, QR 코드 링크에 `?pair={code}&sid={server_id}&pc={hostname}`가 포함되어 **여러 대의 컴퓨터가 있어도 QR 링크가 서로 절대 겹치지 않고 완전히 고유하게 구분**됩니다.
- **초간편 페어링:** PC 화면 상단의 **[📱 스마트폰 연동]**을 눌러 QR 코드를 스마트폰 기본 카메라로 비춥니다.
- **1회 승인 팝업:** 폰 브라우저에 `"연결 대상: [내 컴퓨터 이름] (고유 ID: dp_xxxx) (이 컴퓨터가 맞습니까?)"` 창이 뜨면 **[예, 연동하기]**를 탭합니다.
- **영구 자동 재연동 & 멀티 PC 격리 저장:** 스마트폰 `localStorage`에 PC별 토큰(`deskpilot_token_{server_id}`)을 각각 독립 보관하여, 여러 대의 컴퓨터(집, 회사 등)를 번갈아 사용해도 토큰이 덮어씌워지지 않고 각 PC별로 매끄럽게 자동 재연결됩니다.
- **기기 연동 관리:** PC의 [설정] 탭에서 현재 등록된 스마트폰 기기 목록(기기명, 등록일, 최근 사용 시간)을 확인하고 원클릭으로 연결을 해제할 수 있습니다.

### 4) 📤 크로스 디바이스 파일 공유 (QuickDrop) & 클립보드 텍스트/링크 즉시 전송
- **PC ➡️ 스마트폰:** PC 화면의 QuickDrop 영역에 파일을 끌어다 놓으면 즉시 업로드되어 스마트폰에서 다운로드할 수 있습니다.
- **스마트폰 ➡️ PC:** 폰에서 [사진/파일 선택하여 전송하기]를 누르면 컴퓨터의 `문서\DeskPilot\공유_파일`로 초고속 전송됩니다.
- **클립보드 텍스트 및 링크 즉시 전송:** 파일 생성 없이 텍스트 메모나 웹 URL을 즉시 입력하여 전송할 수 있습니다. URL은 자동으로 링크 형태와 [열기] 버튼으로 렌더링되며, 모든 기기에서 원클릭 [복사] 버튼으로 클립보드에 바로 담을 수 있습니다. 발신 기기 배지(`💻 PC` / `📱 스마트폰`)와 전송 시간이 함께 표시됩니다.
- **폴더 바로 열기:** PC 대시보드에서 [공유 폴더 열기] 버튼을 누르면 윈도우 탐색기로 즉시 해당 폴더가 열립니다.

### 5) 🖥️ 스마트폰에서 실시간 컴퓨터 화면 & 열려있는 창 목록 보기 (Screen Viewer)
- **모바일 하단 [PC 화면] 탭 & 퀵 진입 목록:** 스마트폰이 컴퓨터와 연동되어 있을 때 모바일 메인 상단 퀵 카드, 설정의 [컴퓨터 화면 띄우기] 목록, 또는 하단 내비게이션의 **[PC 화면]** 탭을 터치하여 바로 진입할 수 있습니다.
- **무지연 실시간 라이브 스트리밍 (Ultra-Fast Live Streaming):** 기존의 3초 간격 새로고침 방식을 완전히 탈피하여, 네트워크 상황에 맞게 자동으로 최적화되는 **적응형 라이브 스트리밍(Adaptive Frame Loop)**을 탑재했습니다. RTT 지연시간(ms)을 실시간으로 표시하며 초당 최대 12~15 FPS의 끊김 없는 실시간 화면을 제공합니다.
- **외부 네트워크(LTE/5G/Cloudflare 터널) 완벽 지원:** "외부 네트워크 접속" 토글이 켜져 있는 상태에서도 인증 토큰 및 쿼리 파라미터 연동을 통해 LTE/5G 환경에서 컴퓨터 화면과 창 목록이 100% 정상 공유됩니다.
- **화질 선택 모드:** `⚡ 초고속 실시간` (960px, 압축 품질 60, 약 35KB 초경량으로 모바일 데이터 절약 및 빠른 반응 속도) 및 `🌟 고화질` (1280px, 품질 75) 중 원하는 모드를 선택할 수 있습니다.
- **터치 확대 & 전체화면 모달:** 폰에서 이미지를 탭하거나 [크게 보기]를 누르면 검은색 전체화면 모달로 전환되어 디테일한 글씨와 작업 내용을 크게 볼 수 있습니다.
- **현재 PC에서 열려있는 창 목록 & 원클릭 복사:** 바탕화면에 현재 띄워져 있는 프로그램 창(웹 브라우저, 디스코드, 카카오톡, IDE, 파일 탐색기 등)의 제목과 앱 유형, 크기를 일목요연하게 카드로 표시하며, 각 창을 터치하면 프로그램 제목을 클립보드로 즉시 복사할 수 있습니다.

### 6) 🔄 실시간 수시 동기화 엔진 (Realtime Auto-Sync)
- **수시 자동 갱신:** 2.5초 간격으로 백그라운드에서 동작하여 다음 항목들을 지속적으로 실시간 동기화합니다:
  - 스마트폰에서 추가/완료/삭제한 **할 일 목록**
  - 스마트폰에서 수정한 **메모** (사용자가 타이핑 중일 때는 덮어쓰지 않도록 안전 보호)
  - 양방향으로 전송된 **공유 파일 목록**
  - 새로 연동되거나 해제된 **스마트폰 기기 목록**
  - 바탕화면/다운로드의 **정리 대상 파일 수**
- **스마트 최적화:** 브라우저 탭이 숨겨져 있을 때는 주기적으로 절전 모드로 전환되며, 창을 다시 클릭하거나 활성화하면 즉각 동기화를 재개합니다.

### 1. 기본 실행 방법
- **방법 1 (무음 백그라운드 실행 - 권장):** [run.vbs](file:///c:/Users/cheon/Desktop/임시%20만들거/run.vbs)를 더블클릭합니다. 검은색 콘솔 창 없이 브라우저 대시보드가 열립니다.
- **방법 2 (일반 실행):** [start.bat](file:///c:/Users/cheon/Desktop/임시%20만들거/start.bat)을 더블클릭합니다.
- **접속 주소:** 웹 브라우저에서 `http://localhost:48290`으로 접속합니다.

### 2. 윈도우 부팅 시 자동 실행 설정
- 대시보드 우측 상단의 **[부팅 자동실행]** 토글 스위치(또는 [설정] 탭)를 켜기만 하면, 윈도우 시작프로그램에 등록되어 컴퓨터 부팅 시 자동으로 백그라운드 실행됩니다.

### 3. 원클릭 자동 설치 프로그램 (.exe) 생성 및 배포
다른 사람에게 공유하거나 다른 컴퓨터에 설치할 때 **더블클릭만 하면 자동으로 PC에 설치되는 단일 설치 파일**을 만들 수 있습니다:

1. 폴더 내 [build_installer.bat](file:///c:/Users/cheon/Desktop/임시%20만들거/build_installer.bat)을 더블클릭합니다.
2. `dist\DeskPilot-Setup.exe` 단일 설치 파일이 생성됩니다.
3. 이 `DeskPilot-Setup.exe` 파일을 열면:
   - 별도의 파이썬 설치 없이, 관리자 권한(UAC) 요청 없이 `%LOCALAPPDATA%\Programs\DeskPilot`에 자동 설치됩니다.
   - 바탕화면과 시작 메뉴에 **DeskPilot 바로가기 아이콘**이 자동 생성됩니다.
   - 윈도우 부팅 시 백그라운드 자동 실행이 등록됩니다.
   - 설치 완료 즉시 DeskPilot이 자동 실행되며 웹 대시보드가 뜹니다.
   - 윈도우 [설정 > 앱 > 설치된 앱]에 정식 프로그램으로 등록되며, 언제든 `uninstall.bat`으로 깔끔하게 삭제할 수 있습니다.

### 4. 독립 실행형 포터블 바이너리 (.exe) 배포 빌드
- 설치 과정 없이 무설치 압축 폴더 형태로 바로 실행하게 하고 싶다면:
  - [build_exe.bat](file:///c:/Users/cheon/Desktop/임시%20만들거/build_exe.bat)을 실행하여 생성된 `dist\DeskPilot\` 폴더를 압축해서 공유하시면 됩니다.

## 🌐 7. GitHub 업로드 및 공유 가이드 (GitHub Repository & Releases)

DeskPilot을 GitHub에 올려 다른 사람들과 공유하거나 다른 컴퓨터에서 편하게 받아서 쓰려면 아래 방법을 이용하시면 됩니다:

### 💡 GitHub에 올려두면 좋은 점
1. **간편한 공유:** 소스 코드와 설명서가 링크 하나로 깔끔하게 정리되어 누구나 프로젝트를 쉽게 둘러보고 클론할 수 있습니다.
2. **Releases 배포 기능:** `build_exe.bat`으로 만든 `DeskPilot.exe` 실행 파일(압축 zip)을 GitHub **[Releases]** 탭에 첨부해 두면, 상대방이 파이썬을 설치하지 않아도 더블클릭 실행 파일만 바로 다운로드할 수 있습니다.
3. **코드 백업 및 버전 관리:** 컴퓨터를 바꾸거나 포맷하더라도 언제든 최신 코드를 안전하게 복구할 수 있습니다.

### 방법 1. GitHub 웹에서 바로 업로드 (가장 간단한 방법 - 프로그램 설치 불필요)
1. **[GitHub](https://github.com)**에 로그인한 뒤 우측 상단 `+` 버튼 ➡️ **[New repository]**를 클릭합니다.
2. Repository name에 `DeskPilot`을 입력하고 **[Create repository]**를 누릅니다.
3. 생성된 빈 저장소 화면 중앙의 **"uploading an existing file"** 링크를 클릭합니다.
4. 현재 폴더의 파일(`app.py`, `auth.py`, `organizer.py`, `task_scorer.py`, `file_share.py`, `tunnel.py`, `README.md`, `static/` 폴더 등)을 드래그하여 올린 뒤 **[Commit changes]**를 누르면 완료됩니다!

### 방법 2. GitHub Desktop 사용 (GUI로 편리하게 관리 - 권장)
1. [GitHub Desktop 공식 사이트](https://desktop.github.com)에서 프로그램을 설치하고 GitHub 계정으로 로그인합니다.
2. **[File]** ➡️ **[Add Local Repository]**를 누르고 현재 작업 폴더(`c:\Users\cheon\Desktop\임시 만들거`)를 선택합니다.
3. **[Publish repository]** 버튼을 누르면 원클릭으로 GitHub에 업로드됩니다.

### 방법 3. Git 터미널 CLI 방식
Git for Windows가 설치되어 있다면 콘솔에서 다음 명령어로 업로드할 수 있습니다:
```bash
git init
git add .
git commit -m "DeskPilot v2.0 초기 릴리즈"
git branch -M main
git remote add origin https://github.com/사용자아이디/DeskPilot.git
git push -u origin main
```

> **참고 (보안 및 제외 파일):**  
> 프로젝트 내에 이미 `.gitignore` 파일이 설정되어 있으므로, 불필요한 컴파일 캐시(`__pycache__`), 빌드 임시 파일(`dist/`, `build/`), 사용자 개인 로그(`*.log`) 등은 GitHub에 업로드되지 않고 안전하게 제외됩니다.
